# Support

## Where to ask

- Use GitHub Discussions when enabled for usage questions and design conversations.
- Use the bug-report issue form for reproducible defects.
- Use the feature-request form for scoped enhancement proposals.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities; never disclose them in a public issue.

## Information to include

- TraceLens commit or release version.
- Operating system and Docker version.
- Deployment mode and affected service.
- Reproduction steps, expected result, and actual result.
- Relevant logs with credentials, tokens, personal data, and customer evidence removed.
- Timestamp and timezone.

Community support is best effort. No commercial SLA is provided by this repository.
