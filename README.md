# LogInvestigator-X

Drift-Aware, Evidence-Grounded Agentic AI untuk investigasi log dan anomaly detection via MCP.

(diisi lengkap di Fase 10 — Finalisasi)

## Prasyarat
- Python 3.10+
- Ollama terinstall (`ollama pull llama3.1:8b`)

## Instalasi
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Cara Menjalankan Dashboard
```bash
streamlit run app/ui/main.py
```
(belum tersedia — akan dibuat di Fase 8)
